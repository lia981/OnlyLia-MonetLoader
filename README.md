Collection of MonetLoader scripts and learning resources for SA-MP Android.

## 📜 About This Repository

This repository contains simple MonetLoader scripts created for beginners who want to learn Lua scripting and mimgui for SA-MP Android.

The scripts are designed to be simple, readable, and easy to modify.

# 📚 Script 1 — Basic Learning

**File:**

`OnlyLia_Basic_Learning.lua`

A simple MonetLoader script created for beginners who want to learn the basic structure of Lua scripting.

## ✨ Commands

```text
/liahello
/liainfo
```

### `/liahello`

Displays a simple greeting message in the SA-MP chat.

### `/liainfo`

Displays information about the script and its author.

## 💻 What You Can Learn

- Lua script structure
- Using `require`
- The `main()` function
- Script loops
- Using `wait(0)`
- Detecting SA-MP availability
- Sending chat messages
- Creating SA-MP commands
- Basic MonetLoader scripting

# 🖥️ Script 2 — Basic mimgui UI

**File:**

`OnlyLia_Basic_mimgui.lua`

A simple mimgui script created for beginners who want to learn how to create UI windows in MonetLoader.

## ✨ Command

```text
/liaui
```

## 🖱️ UI Features

- Open and close a window
- Display text
- Create buttons
- Send a message from a button
- Basic mimgui window structure

## 💻 What You Can Learn

- `require "mimgui"`
- `imgui.new.bool()`
- `imgui.OnDrawFrame()`
- `imgui.Begin()`
- `imgui.End()`
- `imgui.Text()`
- `imgui.Button()`
- `imgui.SameLine()`
- Basic UI logic

# 🕒 Script 3 — Basic Clock HUD

**File:**

`OnlyLia_Basic_ClockHUD.lua`

A simple realtime Clock HUD created for learning how to display information on the screen using mimgui.

## ✨ Command

```text
/liahud
```

Use the command to enable or disable the Clock HUD.

## 🖥️ HUD Features

- Realtime system clock
- Displays hours, minutes, and seconds
- HUD overlay
- ON/OFF toggle command
- Transparent background
- Automatic realtime updates

## 💻 What You Can Learn

- `os.date()`
- Realtime updates
- HUD positioning
- `imgui.SetNextWindowPos()`
- `imgui.SetNextWindowBgAlpha()`
- `imgui.WindowFlags`
- Creating a simple overlay
- Toggle systems

# 📥 Installation

1. Download the `.lua` script you want to use.
2. Move the script into your MonetLoader scripts folder.
3. Start or restart SA-MP Android.
4. MonetLoader will load the script automatically.
5. Use the available command in-game.
