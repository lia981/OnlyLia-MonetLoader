# 🎮 OnlyLia MonetLoader

Collection of MonetLoader scripts and learning resources for SA-MP Android.

---

## 📜 Basic Learning Script

**File:**

`OnlyLia_Basic_Learning.lua`

A simple MonetLoader script created for beginners who want to learn the basic structure of Lua scripting for SA-MP Android.

---

## ✨ Commands

```text
/liahello
/liainfo
```

### `/liahello`

Displays a simple greeting message in the SA-MP chat.

### `/liainfo`

Displays information about the script and its author.

---

## 📥 Installation

1. Download `OnlyLia_Basic_Learning.lua`
2. Move the file to your MonetLoader scripts folder
3. Start or restart SA-MP Android
4. MonetLoader will load the script automatically
5. Use the available commands in-game

---
